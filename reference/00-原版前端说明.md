## 3. 加载形态

`index.html` 按顺序 `<script src="module/xxx.js">` 加载约 60 个模块，全是**顶层 `var` 的 IIFE**，天然挂 `window`；
12 个 `<link>` 加载 CSS；无打包器、无 import/export、无 TypeScript、无构建步骤。
`window.USE_CDN = false`（`index.html:1320`），CDN 代码整段在 HTML 注释里，**运行时不访问外网**。
唯一残留外链是玩法说明按钮 `https://rentry.org/how2playJXZ`，仅点击时才打开。

关键模块：`game-config.js`(静态配置) → `game-state.js`(状态) → `api-service.js`(网络) →
`prompt-builder.js` → `pipeline.js`(单轮调度) → `response-parser.js` → `game-ui.js`(渲染) →
`storage-service.js`(存档)。`gameData` 是 `game-state.js:58` 顶层 `let`。

## 4. 覆盖层机制（R3，请务必理解）

完整原版**只读、一字不改**。本地服务按以下顺序找文件：

```
/game/<path>  →  client/<path>  →  char_card_1-main/<path>  →  404
                  （覆盖层）         （100% 原版基座）
?raw=1                          →  跳过覆盖层，直接读基座
```

`client/` 目前只有 7 个文件：`index.html`（4 行微调版）、`adapter/tweaks.css`（统筹微调层）、
`adapter/README.md`、`patches/` 3 份说明、`client/README.md`。
**你产出的 7 个 JS 全部落在 `client/adapter/`**，服务会自动优先命中它们，无需复制任何原版文件。

`index.html.diff` 是当前唯一登记的上游改动（4 行）：
1. viewport 去掉 `maximum-scale=1.0, user-scalable=no`（手机可缩放）；
2. `</head>` 前加一行 `<link rel="stylesheet" href="adapter/tweaks.css?v=1">`。

## 5. 本地服务已具备的能力（不用你实现）

- 全量 mime（webp / mp3 / glb / ttf / wasm / gif / svg …）、中文与空格路径 `decodeURIComponent`；
- HTTP `Range`（mp3 拖动、18MB gif / 16MB glb 流式，不整文件进内存）；
- HTML/JS/CSS `no-store`（刷新即生效），素材 `max-age=86400` + `ETag`（906MB 不重复下载）；
- 目录穿越防护；缺失资源 **404**（不再用占位图掩盖）；
- `GET /api/_debug/assets` 返回原版基线统计（3109 文件 / 898MB），可随时核对 100% 素材在位；
- 只绑 `127.0.0.1`，不访问外网，不调 LLM。
